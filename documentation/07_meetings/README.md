# Team Meetings (`07_meetings/`)

## 1. Purpose
Record official meeting minutes, architectural alignments, task allocations, and decisions agreed upon by team members during syncs.

## 2. Naming Convention
Files must follow the ISO date format: `YYYY-MM-DD-meeting.md` (e.g. `2026-10-20-phase-1-review.md`).

## 3. Template Usage
Copy [`TEMPLATE.md`](TEMPLATE.md) for every team sync or instructor meeting.
