# Working Drafts (`05_drafts/`)

## Purpose
Incubate rough proposals, emerging architectural diagrams, and experimental API designs before opening them to team debate.

## Lifecycle
1. **Creation**: Write draft using `TEMPLATE.md`.
2. **Refinement**: Iterate privately or with AI assistance.
3. **Promotion**: Once mature, promote to `documentation/` following the workflow in `my_workspace/README.md`.
