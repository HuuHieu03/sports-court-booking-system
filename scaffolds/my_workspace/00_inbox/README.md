# Inbox (`00_inbox/`)

## Purpose
The inbox is a scratchpad for rapidly dumping raw thoughts, unverified ideas, snippet links, and quick questions without worrying about structure.

## Rules & Lifecycle
1. **Low Friction**: Drop files or append notes here anytime.
2. **Weekly Zero-Inbox Processing**:
   - Move daily logs to `01_worklogs/`.
   - Move architectural / conceptual notes to `02_notes/`.
   - Move deep technical investigations to `03_research/`.
   - Move formal proposals to `05_drafts/`.
   - Delete obsolete scratch entries.
