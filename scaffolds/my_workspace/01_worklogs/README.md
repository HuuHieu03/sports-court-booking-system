# Personal Worklogs (`01_worklogs/`)

## Purpose
Track personal daily activities, thought processes, micro-decisions, and implementation struggles.

## Personal Worklog vs Official Team Worklog
- **Personal Worklog (`my_workspace/01_worklogs/`)**: Informal, detailed record of what you individually tried, debugged, and learned on a given date. Never pushed to Git.
- **Team Worklog (`documentation/05_development/`)**: High-level team sprint summaries, integrated milestone progress, and formal assignment deliverables shared with course instructors.

## Naming Convention
Use ISO date format: `YYYY-MM-DD-worklog.md` (e.g., `2026-10-15-worklog.md`).
